
## מה נבנה בשלב זה (MVP)

בקשתך היא למערכת רחבה מאוד. אבנה תחילה MVP מלא ועובד לפי הרשימה שהגדרת בסוף ("שלב ראשון לביצוע"), עם תשתית מוכנה להרחבות הבאות (טיפולים/משימות/דוחות מתקדמים/התראות/הגדרות).

## Backend — Lovable Cloud (Supabase)

הפעלה של Lovable Cloud ויצירת סכמה מלאה עם RLS:
- `yeshivas`, `classes`, `students`, `study_sessions`
- `attendance_reports`, `attendance_records`
- `student_events`, `student_treatments`, `treatment_updates`, `tasks`
- `profiles` (משתמש ↔ ישיבה) + `user_roles` עם enum `app_role` (`admin`, `staff`, `viewer`) בטבלה נפרדת
- פונקציית `has_role()` security definer
- RLS: כל משתמש רואה רק את הישיבה שלו; staff/viewer לפי שיוך
- Storage bucket פרטי `attendance-reports` למסמכים סרוקים
- נתוני seed: ישיבה, 3 סדרים (א׳/ב׳/ג׳), 2 שיעורים, מספר בחורים לדוגמה
- GRANTs מפורשים לכל טבלה

## Frontend — React + TanStack Start + Tailwind, RTL עברית

מבנה תיקיות: `components/`, `routes/`, `services/`, `hooks/`, `types/`.

עיצוב: `dir="rtl"` על ה-html, tokens עבריים ב-`styles.css`, פונט עברי (Heebo), תפריט צד ימני, פלטת צבעים נקייה.

### מסכים ב-MVP
1. **התחברות/הרשמה** (Email+Password) + יצירה אוטומטית של profile
2. **אשף קליטה ראשונית** (3 שלבים: ישיבה → שיעורים → העלאת בחורים)
3. **לוח בקרה** בסיסי: פעילים, נוכחים היום, מאחרים, נעדרים, דוחות ממתינים
4. **ניהול שיעורים** (CRUD)
5. **רשימת בחורים** — חיפוש, סינון לפי שיעור/סטטוס, מיון, pagination, ייצוא CSV
6. **קליטת בחורים בכמות** — הדבקה/CSV, מיפוי עמודות, זיהוי כפילויות, תצוגה מקדימה
7. **כרטיס בחור** — לשוניות: פרטים, נוכחות (טבלה + לוח שנה חודשי), אירועים (הוספה), טיפולים בסיסי
8. **העלאת דוח נוכחות** — תאריך, סדר, שיעור, קובץ → Storage → קריאה ל-`attendanceDocumentProcessor` (mock)
9. **מסך אימות דוח** — Split view: תצוגת קובץ בצד ימין, טבלת בחורים בצד שמאל עם רדיו א׳/ב׳/ג׳/חסר/מוצדק, צבעים, סינונים, "אשר ועדכן נוכחות"
10. **דוח נוכחות בסיסי** — לפי תאריך/סדר/שיעור
11. **הגדרות סדרים** — עריכת שעות סף

### שכבת שירות `attendanceDocumentProcessor`
מודול בודד עם interface אחיד. מימוש mock מחזיר סימונים אקראיים+confidence לכל בחור בשיעור. ניתן להחליף בעתיד ב-OCR/AI בלי לגעת ב-UI.

## מה נדחה לשלבים הבאים (אחרי אישור MVP)
- דוחות מתקדמים (חודשי/לפי שיעור/איחורים/היעדרויות/טיפולים/אישי), ייצוא PDF/הדפסה
- מנגנון התראות אוטומטיות עם ספים
- ניהול משתמשים מלא, לוג פעולות, soft delete מלא
- לשוניות משימות/מסמכים מלאות בכרטיס בחור
- טעינת רשימות בחורים מ-Excel/Word/PDF/תמונה (ב-MVP: CSV/הדבקה בלבד)
- חיבור OCR/AI אמיתי

## פרטים טכניים
- Auth: Email+Password (כפי שדרוש). אשאל אם רוצה גם Google.
- ולידציה: Zod בטפסים
- שאילתות: TanStack Query + createServerFn היכן שצריך זהות משתמש
- טבלאות גדולות: pagination בצד שרת
